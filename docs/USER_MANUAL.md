# คู่มือการใช้งานระบบ (User Manual)
**โครงการ:** ระบบบริหารจัดการและซื้อ-ขายไก่ชนออนไลน์ (Gamecock Farm & E-Commerce Platform)

---

## ส่วนที่ 1: คู่มือสำหรับลูกค้า (Storefront User Guide)

### 1.1 การเลือกชมไก่ชนและตรวจดูผังสายเลือด
1. ไปที่เมนู **"ไก่ชนมีชีวิต"** หน้าแรกของเว็บไซต์
2. ใช้ตัวกรองอัจฉริยะ (Smart Filter) ด้านบน เพื่อค้นหาตาม:
   - สายพันธุ์ (พม่ารำวง, ป่าก๋อยพัฒนา, เชิงไทย)
   - ลีลาเชิงชน (ม้าล่อสปีด, กัดหลังทุบข้อหัว ฯลฯ)
   - ป้ายกำกับพิเศษ (`ดาวรุ่ง`, `แชมป์เปี้ยน`, `ไก่หนุ่มคัดผ่าน`)
   - ช่วงราคา
3. คลิกที่การ์ดสินค้าเพื่อเปิดหน้าต่าง **"ข้อมูลและผังสายเลือด"**:
   - ตรวจสอบน้ำหนัก อายุ และประวัติไฟต์การชน
   - สลับแท็บ **"ผังสายเลือด 3 รุ่น"** เพื่อดูประวัติสายพันธุ์ย้อนหลัง (พ่อ-แม่, ปู่-ย่า, ตา-ยาย)
   - คลิกที่กล่องของพ่อพันธุ์หรือแม่พันธุ์ เพื่อเปิดดูสถิติและคลิปวิดีโอโชว์เบอร์แข้ง
   - สลับแท็บ **"คลิปวิดีโอเตะเป้า"** เพื่อรับชมคลิปการชนจริง

### 1.2 การสั่งซื้อและการวางมัดจำ 30%
- ลูกค้าสามารถเลือกกดปุ่ม:
  - **"ซื้อราคาเต็ม"**: ชำระค่าตัวไก่เต็มจำนวน
  - **"วางมัดจำ 30%"**: สำหรับไก่ราคาสูง ชำระเพียง 30% เพื่อล็อกสถานะไก่เป็น **"ติดจอง"** โดยระบบจะมีเวลานับถอยหลัง 48 ชั่วโมงเพื่อให้ดำเนินการต่อ

### 1.3 การสั่งซื้อไข่เชื้อรับประกัน
1. ไปที่เมนู **"ไข่เชื้อพร้อมเพาะ"**
2. เลือกขนาดเซ็ตที่ต้องการ (1 ฟอง, 3 ฟอง, 5 ฟอง) เพื่อรับส่วนลดราคาพิเศษ
3. สังเกตแถบ **"โควตาสัปดาห์นี้"** เพื่อดูจำนวนไข่ที่พร้อมจำหน่าย
4. **สำคัญ:** ติ๊กเครื่องหมายถูกที่กล่องข้อความ **"ข้าพเจ้ายอมรับเงื่อนไขการเคลมไข่เชื้อก่อนสั่งซื้อ"** ก่อนกดเพิ่มลงตะกร้า

### 1.4 การชำระเงินและแจ้งโอน (Smart Split Cart & Checkout)
1. กดที่ไอคอน **"ตะกร้าสินค้า"** มุมขวาบน
2. ระบบจะทำการ **แยกบิล (Split Package)** ให้เห็นอย่างชัดเจน:
   - **บิลไก่มีชีวิต:** ค่าจัดส่งรถตู้สัตว์เลี้ยงติดแอร์ (฿600)
   - **บิลไข่เชื้อ/อุปกรณ์:** ค่าจัดส่งพัสดุด่วนกล่องโฟมกันกระแทก (฿80)
3. กด **"ดำเนินการสั่งซื้อ / ชำระเงิน"**
4. กรอกชื่อ เบอร์โทรศัพท์ และจุดนัดรับที่สะดวก
5. สแกน QR PromptPay เพื่อโอนเงินตามยอดรวม
6. กดเลือกรูปเพื่อ **"แนบสลิปการโอนเงิน"** แล้วกดยืนยัน

### 1.5 การติดตามสถานะคำสั่งซื้อและการจัดส่ง
1. กดปุ่ม **"ติดตามขนส่ง"** ที่แถบเมนูด้านบน
2. กรอกเลขคำสั่งซื้อ (เช่น `CF-ORD-...`) หรือเบอร์โทรศัพท์
3. ระบบจะแสดงสถานะ:
   - สำหรับไก่มีชีวิต: แสดงชื่อคนขับรถตู้, เบอร์โทรติดต่อ, ป้ายทะเบียนรถ และจุดนัดรับ
   - สำหรับไข่/อุปกรณ์: แสดงเลขพัสดุ (Tracking Number) พร้อมลิงก์ตรวจสอบ

## ส่วนที่ 2: คู่มือสำหรับผู้ดูแลฟาร์ม (Admin Dashboard User Guide)

### 2.1 การเข้าสู่ระบบหลังบ้าน
- กดปุ่มสลับมุมมองที่แถบด้านบนสุดเป็น **"แอดมิน (Admin)"**

### 2.2 การจัดการออเดอร์ด้วย Kanban Board (`กระดานออเดอร์`)
- บอร์ดแบ่งออกเป็น 4 คอลัมน์ตามขั้นตอนงานจริง:
  1. **รอยืนยันสลิป:** มีออเดอร์ใหม่เข้ามา กดปุ่ม **"ดูสลิปโอนเงิน"** เพื่อตรวจสอบความถูกต้อง หากถูกต้องกด **"อนุมัติสลิป ➔ รอจัดส่ง"**
  2. **รอจัดส่ง:** เตรียมไก่ใส่กรง หรือแพ็กไข่ลงกล่องโฟม กดปุ่ม **"แก้ไขขนส่ง"** เพื่อกรอกข้อมูลคนขับรถตู้ ทะเบียนรถ จุดนัดรับ หรือเลขพัสดุ จากนั้นกด **"ขนส่งออกเดินทาง"**
  3. **จัดส่งแล้ว (เดินทาง):** สถานะระหว่างรถตู้วิ่งส่ง หรือพัสดุอยู่กับขนส่ง
  4. **จัดส่งสำเร็จ:** เมื่อลูกค้าได้รับของเรียบร้อย กด **"ลูกค้ารับของแล้ว ➔ สำเร็จ"** (ระบบจะเปลี่ยนสถานะไก่เป็น **"ขายแล้ว"** อัตโนมัติ)

### 2.3 การจัดการสต๊อกสินค้าและโควตา (`จัดการสต๊อก & โควตา`)
- **ไก่มีชีวิต:** ตรวจสอบสถานะไก่แต่ละตัวในฟาร์ม
- **โควตาไข่เชื้อ:** ตรวจสอบจำนวนไข่คงเหลือของแต่ละคู่ผสม
- **เวชภัณฑ์และอุปกรณ์:** แก้ไขจำนวนสต๊อกสินค้า พร้อมระบบแจ้งเตือนสีแดงอัตโนมัติหากสต๊อกลดลงต่ำกว่าเกณฑ์ขั้นต่ำ (`เตือนใกล้หมด!`)

### 2.4 การดูรายงานเชิงวิเคราะห์ (`รายงานเชิงวิเคราะห์`)
- สรุปยอดคำสั่งซื้อสะสมและอัตราการเติบโต
- แผนภูมิแสดงสัดส่วนรายได้แยกตามประเภทสินค้า
- **ตารางจัดอันดับพ่อ-แม่พันธุ์ทำเงินสูงสุด:** ดูว่าพ่อพันธุ์ตัวไหนสร้างมูลค่าและจ่ายลูกเก่งที่สุด
